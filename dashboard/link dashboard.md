## Notes

The interactive dashboard was developed using MySQL and Looker Studio to perform an end-to-end business performance analysis of the Olist E-Commerce dataset (2016–2018).

Main dashboard sections:
1. Executive Summary.
2. Sales Performance.
3. Customer Analysis.
4. Payment Analysis.
5. Delivery Performance.
6. Customer Satisfaction.
7. Appendix.
